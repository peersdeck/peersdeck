# PeersDeck project campaign images

Store the six demo campaign cover images in this directory:

- `farmlink.jpg` — FarmLink Africa (agriculture)
- `mwangaza.jpg` — Mwangaza Solar (renewable energy)
- `afyalink.jpg` — AfyaLink (healthcare)
- `crafted.jpg` — Crafted Collective (creative industries)
- `routewise.jpg` — RouteWise (logistics)
- `skillspring.jpg` — SkillSpring (education)

Use optimized WebP images, ideally 1200 × 800 pixels. Keep filenames stable because project records and UI may reference these paths.
