# PeersDeck project campaign images

Store the six demo campaign cover images in this directory:

- `farmlink.webp` — FarmLink Africa (agriculture)
- `mwangaza.webp` — Mwangaza Solar (renewable energy)
- `afyalink.webp` — AfyaLink (healthcare)
- `crafted.webp` — Crafted Collective (creative industries)
- `routewise.webp` — RouteWise (logistics)
- `skillspring.webp` — SkillSpring (education)

Use optimized WebP images, ideally 1200 × 800 pixels. Keep filenames stable because project records and UI may reference these paths.
